2. Imagen, color y Python

Representación

  • RGB: matriz alto × ancho × 3.
  • Cada píxel es [R,G,B], normalmente 0–255.
  • [:,:,0] rojo, [:,:,1] verde, [:,:,2] azul.
  • Alpha = transparencia; se ignora si no se usa o se justifica.
  • Ráster = píxeles; vectorial = figuras matemáticas.

Efectos

  • Gris: promedio o ponderación (luma).
  • Brillo sumativo: I'=I+c.
  • Brillo multiplicativo: I'=I×c.
  • Negativo: I'=255-I.
  • Umbral: I<t → 0; I≥t → 1 o 255.
I=80 → negativo=255−80=175; t=100 → 80<100 → 0

3. Ruido y filtros

Ruido

  • Gaussiano: intensidades alteradas según distribución normal.
  • Sal y pimienta: píxeles blancos y negros aislados.
  • El dominio espacial opera sobre los vecinos.

Filtro lineal

El kernel se desliza y combina el vecindario:

g(x,y) = Σ Σ w(s,t) · f(x+s,y+t)

Padding resuelve los bordes; stride indica el paso.

Elección rápida

FiltroQué hace
MediaPromedia; suaviza, pero borra bordes y es sensible a outliers.
GaussianoSuaviza con más peso en vecinos cercanos.
MáximoCombate pimienta: puntos negros.
MínimoCombate sal: puntos blancos.
MedianaOrdena y toma el centro; muy buena contra sal y pimienta.
10,12,13,14,15,16,17,18,250 → media=39,44; mediana=15

4. Bordes

Zona constante → derivada cercana a 0. Cambio brusco → derivada grande → candidato a borde.

Laplaciano

0 1 0 1 -4 1 0 1 0

Segunda derivada; sensible al ruido y sin dirección.

Gradiente / Sobel

∇f=[gx,gy]; M=√(gx²+gy²)≈|gx|+|gy|; θ=arctan(gx/gy)

Magnitud = fuerza; dirección = hacia dónde cambia.

Canny

Gaussiano→Sobel / gradiente→No máximo→Histéresis

No máximo: conserva máximos locales. Histéresis: sobre Th es fuerte, bajo Tl se descarta y entre ambos se conserva si conecta con uno fuerte.

5. Segmentación

Histograma y umbral

h(k)=nₖ cuenta píxeles de intensidad k; p(k)=nₖ/n normaliza.

[20,80,140,220], t=100 → [0,0,1,1]

K-Means

  1. Escoger K centroides.
  2. Asignar cada píxel al más cercano.
  3. Promediar cada grupo.
  4. Repetir hasta que no cambien.
10,12,90,100; K=2 → {10,12}: c₁=11; {90,100}: c₂=95

SLIC

Es K-Means para superpíxeles y usa:

[R,G,B,x,y]

Color + coordenadas producen grupos compactos. compactness balancea color y posición.

Cuantización

  • Median Cut: cubo RGB → canal mayor → ordenar → mediana → repetir.
  • Mean Shift: ventana → centro de masa ponderado → mover → repetir.
  • Tracking: histograma de ROI → mapa de confianza → Mean Shift.

6. Cálculos esenciales

Media 3×3

10 20 30 / 20 40 50 / 30 50 60 → suma=310 → salida=310/9=34,44≈34

Suaviza, pero puede perder bordes.

Laplaciano

Centro 100; N=100, S=100, E=160, O=100:

100+100+160+100 − 4·100 = 60

El 60 indica cambio local.

Sobel

Si gx=30 y gy=40:

M=√(30²+40²)=50; aprox.=30+40=70; θ≈36,9°

Magnitud = fuerza; ángulo = dirección.

Pregunta integradora

Ruido sal y pimienta + contorno:

Primero mediana para quitar outliers. Luego escala de grises si no necesito color. Finalmente Canny: Gaussiano, gradiente/Sobel, supresión no máxima e histéresis. No empezaría con Laplaciano porque es muy sensible al ruido.
